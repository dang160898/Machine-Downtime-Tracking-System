# Machine Downtime Dashboard — Vercel deployment (ฉบับมือใหม่ ไม่ต้องใช้ command line)

คู่มือนี้ใช้วิธีอัปโหลดผ่านเว็บล้วนๆ ไม่ต้องติดตั้งโปรแกรมอะไรเพิ่มในเครื่อง
ไม่ต้องรู้จัก terminal หรือคำสั่งใดๆ เลย

## สิ่งที่ต้องเตรียม
- ไฟล์ในโฟลเดอร์นี้ (แตกจาก zip แล้ว)
- อีเมล 1 อัน (ใช้สมัครทั้ง GitHub และ Vercel)

---

## ขั้นที่ 1 — สมัคร GitHub (ถ้ายังไม่มีบัญชี)
1. ไปที่ https://github.com/signup
2. กรอกอีเมล ตั้งรหัสผ่าน ตั้งชื่อผู้ใช้ ทำตามขั้นตอนยืนยันตัวตนจนเสร็จ
3. ล็อกอินเข้าหน้าหลักของ GitHub ให้เรียบร้อย

## ขั้นที่ 2 — สร้าง Repository ใหม่
1. มุมขวาบนของหน้า GitHub กดเครื่องหมาย **+** → เลือก **New repository**
2. ช่อง Repository name พิมพ์ชื่อ เช่น `machine-dashboard`
3. เลือก **Private** (ส่วนตัว ไม่ต้องเป็นสาธารณะ)
4. เลื่อนลงล่างสุด กด **Create repository**

## ขั้นที่ 3 — อัปโหลดไฟล์ขึ้น GitHub
1. ในหน้า repo ที่เพิ่งสร้าง จะมีลิงก์เขียนว่า **"uploading an existing file"** — คลิกที่ลิงก์นั้น
2. ลากไฟล์ `index.html`, `package.json`, `README.md` จากในเครื่องคุณ วางลงในกล่องที่ขึ้นมา
3. **สำหรับโฟลเดอร์ `api`** (มีไฟล์ `storage.js` อยู่ข้างใน) — ลองลากทั้งโฟลเดอร์ `api` ใส่เข้าไปเลย เบราว์เซอร์ส่วนใหญ่รองรับ ถ้าลากไม่ติด/ไม่ขึ้น ให้ทำแบบนี้แทน:
   - กลับไปหน้า repo หลัก → กด **Add file → Create new file**
   - ช่องชื่อไฟล์ พิมพ์ว่า `api/storage.js` (พิมพ์เครื่องหมาย `/` เข้าไปด้วย ระบบจะสร้างโฟลเดอร์ `api` ให้เองอัตโนมัติ)
   - เปิดไฟล์ `api/storage.js` ในเครื่องคุณด้วย Notepad (Windows) หรือ TextEdit (Mac) → คัดลอกโค้ดทั้งหมด → วางในช่องข้อความของ GitHub
   - เลื่อนลงล่างกด **Commit changes**
4. เลื่อนลงล่างสุดของหน้าอัปโหลด กด **Commit changes** อีกครั้งเพื่อบันทึกไฟล์ทั้งหมด

## ขั้นที่ 4 — สมัคร Vercel และเชื่อมกับ GitHub
1. ไปที่ https://vercel.com/signup
2. กด **Continue with GitHub**
3. ระบบจะพาไปหน้า GitHub ให้กด **Authorize Vercel** (อนุญาตให้ Vercel เห็น repo ของคุณ)

## ขั้นที่ 5 — นำโปรเจกต์เข้า Vercel (Import)
1. หลังล็อกอิน จะเห็นหน้า Dashboard ของ Vercel → กด **Add New...** → **Project**
2. จะเห็นรายชื่อ repository ของคุณ หา `machine-dashboard` (ที่สร้างไว้ขั้นที่ 2) → กด **Import**
3. หน้าตั้งค่าที่ขึ้นมา **ไม่ต้องแก้อะไรเลย** ปล่อยค่าเริ่มต้นทั้งหมด → เลื่อนลงกด **Deploy**
4. รอประมาณ 30 วินาที - 1 นาที จะขึ้นหน้า "Congratulations 🎉" พร้อมรูปหน้าเว็บ

## ขั้นที่ 6 — เพิ่มฐานข้อมูล (Vercel KV)
1. จากหน้า Congratulations กด **Continue to Dashboard** (หรือคลิกชื่อโปรเจกต์จากหน้าแรก)
2. แถบเมนูด้านบนของหน้าโปรเจกต์ กดแท็บ **Storage**
3. กด **Create Database**
4. เลือกประเภท **KV** (ถ้าเห็นชื่อ Upstash for Redis หรือคล้ายกันปนอยู่ ให้เลือกอันที่ระบุว่า KV)
5. ตั้งชื่อฐานข้อมูล (ชื่ออะไรก็ได้ เช่น `dashboard-db`) → กด **Create**
6. ระบบจะถามว่าจะเชื่อมกับโปรเจกต์ไหน → เลือก `machine-dashboard` → กด **Connect**
   (ขั้นตอนนี้ Vercel จะตั้งค่าที่จำเป็นให้อัตโนมัติทั้งหมด ไม่ต้องคัดลอกอะไรเอง)

## ขั้นที่ 7 — Deploy ใหม่อีกครั้ง (ให้ฐานข้อมูลมีผล)
1. กดแท็บ **Deployments** ด้านบนของหน้าโปรเจกต์
2. แถวบนสุด (deployment ล่าสุด) มีจุดสามจุด **⋯** ด้านขวา → กด → เลือก **Redeploy**
3. กดยืนยัน **Redeploy** อีกครั้งในกล่องที่ขึ้นมา → รอจนเสร็จ (ขึ้นเครื่องหมายถูกสีเขียว)

## ขั้นที่ 8 — ทดสอบว่าใช้งานได้จริง
1. กดปุ่ม **Visit** (หรือคลิกลิงก์ที่ขึ้นต้นด้วย `https://...vercel.app`) เพื่อเปิดเว็บ
2. ลองเพิ่มเครื่องจักร 1 เครื่อง → กด refresh หน้าเว็บ (F5) → เช็คว่าเครื่องที่เพิ่มยังอยู่
3. คัดลอกลิงก์เดียวกันไปเปิดในมือถือ → เช็คว่าเห็นข้อมูลตรงกับในคอม

## ขั้นที่ 9 — ย้ายข้อมูลเก่าจาก artifact เดิม (ถ้ามี)
1. เปิดลิงก์ artifact เดิม → **⚙ ผู้ดูแลระบบ → ส่งออกข้อมูลสำรอง (JSON)**
2. เปิดเว็บใหม่ (ลิงก์ vercel.app) → **⚙ ผู้ดูแลระบบ → นำเข้าจากไฟล์สำรอง** → เลือกไฟล์ที่เพิ่ง export

## ขั้นที่ 10 — แชร์ให้ทีม
คัดลอกลิงก์ `https://your-project.vercel.app` ส่งให้ทีม 5-6 คนได้เลย นี่คือลิงก์ถาวร ไม่ต้อง publish ซ้ำอีกแล้ว

---

## แก้ปัญหาที่มักเจอ
- **ลากโฟลเดอร์ api ไม่ติด** → ใช้วิธี "Create new file" พิมพ์ชื่อ `api/storage.js` ตามขั้นที่ 3
- **Deploy แล้ว error "Cannot find module @vercel/kv"** → เช็คว่าไฟล์ `package.json` อัปโหลดขึ้นไปครบถ้วน แล้วลอง Redeploy อีกครั้ง (ขั้นที่ 7)
- **เว็บเปิดได้แต่ข้อมูลไม่เซฟ / กดอะไรไม่ขึ้น** → เข้าแท็บ Storage เช็คว่าฐานข้อมูลขึ้นสถานะเชื่อมต่อ (Connected) กับโปรเจกต์แล้วจริงหรือยัง ถ้ายัง ให้กด Connect ใหม่แล้ว Redeploy อีกครั้ง
- **ไม่รู้จะหาปุ่มไหน** → screenshot หน้าจอที่ติดปัญหาส่งมาได้เลย ช่วยไล่ดูให้ทีละจุด
